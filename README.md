# LIPO Interpreter

Учебный C++ проект интерпретатора для простого булевого языка. Проект разбирает программу с объявлениями логических переменных, выражениями и присваиваниями, строит промежуточные представления и выполняет мнимокод на стековой машине.

## Возможности

- лексический анализ исходной программы из `source code.txt`;
- синтаксическая проверка программы с записью ошибок в `errors.log`;
- преобразование выражений в постфиксную форму;
- генерация мнимокода с командами `LIT`, `LOAD`, `STO`, `AND`, `OR`, `XOR`, `NOT`;
- интерпретация мнимокода и вывод значений переменных.

## Пример языка

```text
Var a, b, c, d :Boolean;
Begin
a = 0;
b = .NOT. 1;
c = .NOT. (a .OR. b);
d = (c .XOR. a) .AND. b;
End.
```

Поддерживаются булевы константы `0` и `1`, идентификаторы, скобки, присваивание и логические операции `.NOT.`, `.AND.`, `.OR.`, `.XOR.`.

## Структура проекта

| Файл | Назначение |
| --- | --- |
| `main.cpp` | Точка входа приложения. |
| `lexical_analyzer.h` | Разбор исходного текста на лексемы. |
| `syntax_analyzer.h` | Рекурсивный синтаксический анализ грамматики языка. |
| `postfix_analyzer.h` | Преобразование выражений в постфиксную форму с учетом приоритетов. |
| `mnimocode_builder.h` | Генерация мнимокода из постфиксной записи. |
| `interpreter.h` | Стековый интерпретатор команд мнимокода. |
| `Lexem_struct.h` | Общая структура текущей лексемы. |
| `source code.txt` | Пример входной программы. |
| `docs/ARCHITECTURE.md` | Подробное описание архитектуры и потока данных. |

## Запуск

Проект создан как Visual Studio C++ проект:

1. Откройте `interpreter.slnx` или `interpreter.vcxproj` в Visual Studio.
2. Убедитесь, что рядом с исполняемым файлом доступны входные файлы, которые использует выбранный сценарий.
3. Соберите и запустите проект.

Текущая точка входа вызывает `interpretMnimocode()`, поэтому она читает уже готовый `mnimocode.txt`. Для полного конвейера от исходного кода до исполнения используйте функцию `interpret()` из `interpreter.h`.

## Выходные файлы

Во время работы могут создаваться файлы:

- `lexem.txt` - результат лексического анализа;
- `postfix_form.txt` - постфиксная форма выражений;
- `mnimocode.txt` - сгенерированный мнимокод;
- `errors.log` - журнал ошибок анализа.

Эти файлы считаются генерируемыми и не хранятся в репозитории.
