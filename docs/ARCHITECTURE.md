# Архитектура

Проект построен как последовательный конвейер обработки простой булевой программы. Каждый этап получает результат предыдущего этапа через файл и подготавливает данные для следующего этапа.

```text
source code.txt
    |
    v
lexical_analyzer.h  -> lexem.txt
    |
    v
syntax_analyzer.h   -> errors.log
    |
    v
postfix_analyzer.h  -> postfix_form.txt
    |
    v
mnimocode_builder.h -> mnimocode.txt
    |
    v
interpreter.h       -> значения переменных в консоли
```

## Этапы

### 1. Лексический анализ

`lexical_analysis()` читает `source code.txt`, выделяет ключевые слова, идентификаторы, операторы, разделители и константы. Результат записывается в `lexem.txt` в формате:

```text
<номер_строки> <значение> <тип_лексемы>
```

### 2. Синтаксический анализ

`syntax_analysis()` запускает лексический анализ, затем проверяет поток лексем рекурсивным спуском. Функции `S`, `A`, `B`, `C`, `D`, `E`, `F`, `G`, `H`, `O` соответствуют нетерминалам грамматики.

Ошибки записываются в `errors.log` с номером строки, значением лексемы и ее типом.

### 3. Постфиксная форма

`priorityAnalysis()` проверяет синтаксис и вызывает `postfix_record()`. Выражения преобразуются в обратную польскую запись при помощи стека операторов. Приоритеты:

- `NOT` - самый высокий;
- `AND` - средний;
- `OR` и `XOR` - низкий.

### 4. Генерация мнимокода

`mnimocoder()` читает `postfix_form.txt` и создает стековые инструкции:

| Команда | Назначение |
| --- | --- |
| `LIT value` | Поместить константу в стек. |
| `LOAD name` | Поместить значение переменной в стек. |
| `STO name` | Сохранить верхнее значение стека в переменную. |
| `AND`, `OR`, `XOR` | Выполнить бинарную логическую операцию. |
| `NOT` | Выполнить унарное отрицание. |

### 5. Интерпретация

`interpretMnimocode()` читает `mnimocode.txt`, выполняет команды на стеке и хранит значения переменных в `map<string, int>`. После выполнения значения переменных выводятся в консоль.

## Основные ограничения

- Ввод и промежуточные данные передаются через файлы с фиксированными именами.
- Тип данных один: `Boolean`, представленный числами `0` и `1`.
- Текущая `main.cpp` запускает только исполнение готового мнимокода. Полный путь анализа и генерации доступен через `interpret()`.
